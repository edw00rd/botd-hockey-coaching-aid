BOTD HOCKEY COACHING AID — VERSION 3.5
Creator: Nicholas Heller
Release date: 2026-08-02

OVERVIEW

BOTD Hockey Coaching Aid is a standalone HTML5 tactics board for designing,
drawing, animating, saving, and presenting hockey plays. It is intended for a
Windows desktop browser with a mouse and for iPad use with touch or Apple
Pencil. The application is contained in one HTML file and does not require an
installation, account, external JavaScript library, server, or internet
connection.

Nicholas Heller is acknowledged in the HTML source and in this README as the
creator of the application, its product concept, coaching workflow, and feature
direction.

RUNNING ON WINDOWS

1. Extract the ZIP archive to a normal folder.
2. Double-click BOTD_Hockey_Coaching_Aid_v3.5.html.
3. Open it with a current version of Microsoft Edge, Google Chrome, or Firefox.
4. A local file:/// address in the browser is expected. The application runs
   locally and does not need a web server.

Do not run the HTML directly from inside the ZIP archive. Extract it first so
browser storage, image uploads, and file exports behave more consistently.

RUNNING ON IPAD OR WITH APPLE PENCIL

The board uses standard Pointer Events and supports touch, Apple Pencil, mouse,
and trackpad input. For the most consistent iPad experience, place the same HTML
file on a static HTTPS website, open it in Safari, and use Add to Home Screen.
Opening a local HTML file directly from the Files app can depend on the file
provider and the installed iPadOS version.

VERSION 3.5 CHANGES

AUTOMATIC ALL-ON-ICE TURN PARTICIPATION

Starting a turn now includes every player and goalie currently on the ice.
There is no separate participant-selection step. A player who receives no
action remains stationary for that turn, so the coach only edits the objects
that actually change.

Turn-status rings communicate the remaining work:

- Green: the player has not yet received a Skating-lane action for this turn.
- Orange: the player has completed a Move action, still has possession, and may
  still receive the turn's Puck-lane action.
- No status ring: the relevant action lanes are complete, the player has a Line
  switch, or no additional action is available.

These status rings are editing aids. They disappear during playback and active
scrubbing. The existing dotted selection outline also remains hidden during
playback.

ADJUSTABLE PLAYER MOVEMENT SPEED

A player with a recorded Move action now receives a Skating speed editor in the
Selected player card, near the timed pass/shot release controls.

- The range is 0.25x through 3.00x.
- Quick choices are available for 0.5x, 1x, 1.5x, and 2x.
- The authored route shape and endpoints remain fixed.
- The action duration and every timed point on the route are rescaled.
- A Pass or Shoot release assigned to the moving player keeps the same relative
  position on that route.
- Pass lead, release source, moving-receiver timing, and shot geometry are
  recalculated after the speed changes.

This allows a coach to tune timing without redrawing the same skating path.

TOUCH, APPLE PENCIL, AND MOUSE SHOT TARGETING

Shot targeting now uses a press-drag-release interaction:

1. Select Shoot.
2. Press the rink with a mouse, finger, or Apple Pencil.
3. Drag the target reticle to the intended location.
4. Review the transparent preview arrow from the shooter's release point.
5. Lift the pointer to confirm the target and open the shot-power dialog.

The target is not committed on initial contact. A press and release without
moving is also valid, but confirmation still occurs on release rather than on
pointer down.

IGNORE DEFENSE FOR PASSES AND SHOTS

Pass and Shot dialogs now have separate Ignore defense checkboxes.

- Pass defaults to checked.
- Shot defaults to unchecked.
- When enabled, skaters and goalies do not stop that puck event.
- Boards, goal geometry, puck travel timing, shot power, net entry, and other
  rink-boundary behavior remain active.
- When disabled, the established blocked-pass and blocked-shot behavior remains
  available.

The selected setting is stored in the authored action, saved play, playbook, and
JSON export. Timeline summaries identify puck actions that ignore defense.

PLAYER GLOW AND BLINKING HIGHLIGHTS

The Selected player card now contains an optional Glow editor for any on-ice
player or goalie.

- Glow can be enabled or disabled independently per player.
- A native color picker and color-gradient preview select the glow color.
- Brightness is adjustable from 10 percent through 100 percent.
- Blinking is optional.
- Blink rate is adjustable from 0.25 Hz through 4.00 Hz.
- Glow settings persist in browser sessions, saved plays, playbooks, and JSON.

Glow is a presentation aid only. It does not change possession, collision,
team, bench, or action rules. Browsers honoring reduced-motion preferences keep
the glow visible but suppress its blinking animation.

COLLAPSED-WORKSPACE ROUTE CONTROLS

The bottom toolbar continues to expose Play / Stop, Restart, bidirectional
scrubbing, playback speed, and the Recorded routes checkbox when Play Animator
is hidden. When both side drawers are hidden, the toolbar also shows a compact
recorded-route mode selector for:

- All routes;
- Ahead; erase behind; and
- Hidden.

The compact controls remain synchronized with the full Play Animator controls.

TEAM AND RINK WORKFLOW IMPROVEMENTS

- Teams & rink is now capitalized as Teams & Rink.
- Whole ice / Half ice selection is directly below the Teams & Rink helper copy.
- Fresh sessions start with DAWGS in green and black.
- Fresh sessions start with FLAMINGOS in pink and yellow.
- Each team card includes Flip Primary / Trim.
- Flipping team colors immediately updates every inheriting roster, bench, rink,
  selection, and line-change token. Individual player-color overrides remain
  explicit overrides.
- Whole ice remains the default fresh-board view.

FULL-SCREEN FOCUS MODE

Full-screen controls are available in the top bar and bottom drawing toolbar.
The control requests the browser Fullscreen API and simultaneously enters an
app-level focus mode that hides the top bar and both side drawers. When native
full screen is unavailable or declined, the app-level focus layout still
maximizes rink space. Exiting restores the previous drawer state.

The former combined Show names, numbers & positions switch has been replaced by

- Names;
- Numbers;
- Positions; and
- Leadership roles.

Each option affects only rink tokens. Numbers appear in the token center, names
appear below the token, positions appear in a small upper-right badge, and a

Version 3.3 plays that had the old combined label switch enabled migrate with
Names, Numbers, and Positions enabled. Leadership remains independent and is

Every roster player may now override the team's primary and trim colors.

- New and existing players inherit the current team colors by default.
- Primary and Trim color controls appear in every roster row.
- Colors may be set before Load active players to benches is selected.
- Colors may also be changed after a player has already been loaded, placed on
  the ice, selected, or used as a line-change option.
- Bench tokens, rink tokens, the selected-player token, and line-change tokens
  update immediately.
- Selecting Team removes both overrides and returns the player to the team's
  current colors.
- A player may override only one color; the other color continues following the
  team setting.
- Player color overrides persist in the browser, saved plays, playbooks, copied
  turns, and JSON exports.

Changing a team's colors continues to update every player who is inheriting
those colors. Players with explicit overrides retain the overridden values.

VERSION 3.3 CHANGES

DUAL ACTION LANES

Each player may now have two independent action lanes in the same turn:

- Skating lane: Move
- Puck lane: Pass or Shoot

A Line switch remains exclusive and replaces both lanes for that player. The
turn may still contain several simultaneous Move actions, while one Pass or
Shoot event is shared across the turn.

This allows the puck carrier to:

- skate and pass during the same turn;
- skate and shoot during the same turn;
- retain possession before the selected release time;
- release the puck at a precise point on the skating route; and
- continue skating after the puck leaves the stick.

A moving receiver may also have a Move action in that turn. The pass endpoint is
calculated against the receiver's timed route so the puck leads the receiver to
an interception point instead of traveling to the receiver's original location.

TIMED PASS AND SHOT RELEASE

When a puck carrier has both a Move action and a Pass or Shoot action, Version
3.3 exposes an editable release time.

The release may be set in four ways:

- choose At start;
- choose At end;
- preview the turn and choose Set from playhead;
- drag the orange PASS or SHOT marker along the recorded skating route; or
- drag the release-time range control in the selected-player card.

The pass or shot dialog also includes a release-time control. A stationary
player releases at the start of the turn because no skating timeline exists for
that player.

Changing or replacing the passer's Move route automatically recalculates the
release source, pass timing, moving-receiver lead, bank eligibility, and puck
trajectory. Changing the receiver's Move route also recalculates the lead pass.

PASS-ON-THE-MOVE POSSESSION BEHAVIOR

During a timed pass:

- the carrier remains in possession until the release time;
- the puck is loose while traveling;
- the passer continues along the remaining Move route;
- a moving receiver continues along that receiver's own Move route;
- the receiver gains possession when an unobstructed pass arrives; and
- a blocked pass finishes loose at the calculated impact point.

Possession changes authored at the beginning of the turn still take priority.
Changing possession away from the scheduled passer removes an invalid Pass or
Shoot, as in earlier releases.

RESTRICTED BANK-PASS SELECTION

The direct pass is tested first. A bank pass is considered only when the direct
lane is obstructed.

For each candidate wall contact, Version 3.3 calculates:

- L1: distance from the passer's release point to the wall contact; and
- L2: distance from the wall contact to the receiver's predicted arrival point.

A candidate bank is eligible only when L2 is less than or equal to L1. Among
eligible, unobstructed candidates, the shortest total route is selected. If no
candidate satisfies that rule, the app retains the straight pass attempt.

When that retained straight pass intersects a player or goalie, it is recorded
as a blocked pass and the puck remains loose at the impact point. This preserves
the requested straight-pass fallback without allowing the puck to pass through
the blocker and attach incorrectly to the receiver.

For a moving receiver, L2 is measured to the calculated interception position,
not to the receiver's starting position.

BIDIRECTIONAL PLAYBACK SCRUBBING

The playback range control is now a true reversible playhead.

- Drag it to the right to move forward through the play.
- Drag it to the left to reconstruct earlier player and puck states.
- Player positions, line changes, possession, loose-puck location, pass and shot
  flight, puck spin, route traces, and goal visuals are recomputed from the
  authored turn data at the selected time.
- Beginning a scrub pauses active playback so the animation does not fight the
  pointer.
- Scrubbing across a recorded goal displays the correct GOAL! visual state but
  does not repeatedly replay the goal siren.
- Normal forward playback still triggers the siren at the recorded goal time.

CLEANER PLAYBACK VIEW

Dotted player-selection outlines and turn-selection outlines are hidden while
normal playback is running. They return when playback stops so the coach can
continue editing. The outlines are also hidden while the timeline thumb is
actively being dragged.

BASIC WORKFLOW

1. Open Teams to choose Whole ice or Half ice, edit team identities, flip or
   change team colors, and manage the center-ice and playbook images.
2. Open Roster to edit number, name, position, goalie status, captain status,
   alternate status, per-player colors, and active-bench membership.
3. Select Load active players to benches after changing the active roster.
4. Select bench tokens to place players on the ice, then drag them into the
   starting formation.
5. Place the loose puck or assign possession to any on-ice player.
6. Select New turn. Every on-ice player is included automatically and initially
   receives a green editing ring.
7. Select only the players who change in the turn. Record a Move route, assign a
   Line switch, or leave a stationary player untouched.
8. Use the Skating speed control to tune a recorded Move without redrawing it.
9. Assign the one Pass or Shoot event for the turn when needed. Choose whether
   that puck action should Ignore defense.
10. For a moving passer or shooter, set the orange release marker or the
    release-time slider.
11. Select Done turn and repeat for later turns.
12. Press Play to review the sequence, or drag the playback slider in either
    direction to inspect a particular moment.
13. Collapse either drawer, hide both drawers, or enter full-screen focus mode
    when additional rink space is needed. Playback and route controls remain in
    the bottom toolbar.
14. Press Stop at any point and begin a new turn there to branch from that state.
15. Name the playbook and play, then save locally and export JSON backups.

PASSING ON THE MOVE — STEP BY STEP

1. Give the intended passer possession.
2. Select New turn. The passer, receiver, defenders, and every other on-ice
   object are included automatically.
3. Select the passer and record a Move route when the passer is skating.
4. Adjust the passer's Skating speed when the route timing needs refinement.
5. Select the receiver and record the receiver's Move route when applicable.
6. Record routes for any other players changing position in the turn.
7. Select the passer and choose Pass.
8. Select the intended receiver.
9. Choose Flat pass or Saucer pass.
10. Leave Ignore defense checked for an unobstructed teaching pass, or uncheck it
    to use defender, goalie, and bank-pass collision behavior.
11. Set the release time in the dialog, or add the pass and then drag the orange
    marker on the passer's route.
12. Preview the turn with the selected-player preview playhead when more precise
    timing is needed.
13. Select Done turn.
14. Press Play or scrub the timeline. The puck stays with the carrier until the
    release point and then leads a moving receiver.

MOVING SHOT — STEP BY STEP

1. Give the shooter possession.
2. Start a turn and record the shooter's Move route when the shooter is skating.
3. Adjust Skating speed when needed.
4. With that player selected, choose Shoot.
5. Press and drag the target reticle with mouse, touch, or Apple Pencil. Use the
   transparent arrow to preview the shot direction, then lift to confirm.
6. Choose power from 1 through 10.
7. Leave Ignore defense off for normal block detection, or enable it to let the
   shot pass through skaters and goalies.
8. Set the release time in the shot dialog or with the orange SHOT marker.
9. Finish the turn.
10. The skater moves with the puck, releases at the selected time, and continues
    skating while the shot follows the established board, block, and goal
    physics.

TIMELINE SCRUBBING AND BRANCHING

- Dragging the slider automatically stops active playback.
- The slider can be moved repeatedly forward and backward without modifying the
  authored turns.
- To branch, leave the playhead at the desired time, select a player, and choose
  Start turn here or Turn from playhead.
- A branch turn captures player locations, bench state, puck location, and
  possession at that playhead time.
- The GOAL! panel may appear while scrubbing through the short celebration
  window. Audio is reserved for normal forward playback.

SHOT, GOAL, BLOCK, AND RIM-AROUND WORKFLOW

1. Give an on-ice player possession.
2. Start or continue a turn and select that player.
3. Select Shoot.
4. Press, drag, and release the target reticle on the rink.
5. Choose power from 1 through 10 and set Ignore defense as required.
6. For a moving shooter, select the release point.
7. To score, aim so the calculated path crosses the goal line through the
   opening between the posts. The puck finishes inside the net.
8. Complete the turn and press Play. At the recorded goal time, the red lamp,
   GOAL! panel, rink pulse, and browser-generated siren activate.
9. For a rim-around, choose a target at a shallow angle near the boards. The app
   follows the rounded boundary while modeled energy remains.
10. If the path intersects a skater or goalie before entering the net, the shot
    is blocked, performs a short rebound, and ends loose.

STORAGE MIGRATION

Version 3.5 uses the following storage namespaces:

- botdHockeyCoachingAid.session.v3_5
- botdHockeyCoachingAid.playbook.v3_5

When a Version 3.5 record does not yet exist, the app checks Version 3.4 first,
then Version 3.3, Version 3.2, Version 3.1, Version 3.0, Version 0.2.1, Version
0.2, and Version 0.1 records. Existing playbook entries are retained, and
missing BOTD core samples are appended without replacing an entry with the same
identifier or title.

Older storage records are not overwritten. Version 3.5 autosaves later work
under its own keys. Portable JSON files from earlier releases may also be
imported. Version 3.4 display options and player-color overrides remain intact.
Players without glow data receive Glow off, the default yellow glow color, 72
percent brightness, Blinking off, and a 1.50 Hz stored blink rate. Existing
turns are normalized into the automatic all-on-ice authoring workflow without
changing their recorded actions.

Browser storage is isolated by origin. A local file, a GitHub Pages URL, a
custom domain, and a renamed repository can each have separate storage. Export
important playbooks before moving the site or clearing browser data.

VERSION 3.5 TECHNICAL NOTES AND KNOWN LIMITATIONS

- Automatic turn inclusion does not create no-op actions for stationary players.
  The saved turn contains the authored changes while all other on-ice positions
  carry forward unchanged.
- The green ring tracks a pending Skating lane. The orange ring appears only
  after a Move when that same player still possesses the puck and may use the
  Puck lane. Rings are guidance overlays, not recorded animation objects.
- Move speed changes preserve route geometry and rescale timing. They do not
  estimate biomechanical acceleration, edge work, fatigue, or a player's real
  maximum skating speed.
- Ignore defense bypasses skater and goalie interception for that puck action.
  It does not disable boards, rink boundaries, goal detection, net containment,
  shot power, or puck travel time.
- An Ignore-defense pass normally uses the direct route because players and
  goalies are intentionally excluded from obstruction testing.
- Shot targeting confirms on pointer release. The app cannot distinguish a
  deliberate zero-distance drag from a simple tap, so a tap still confirms at
  release rather than requiring visible pointer movement.
- Glow is visual metadata. It does not alter team identity, possession,
  collision radius, line changes, or scoring. Reduced-motion browser settings
  suppress blinking while retaining a steady glow.
- Native full screen depends on browser support, user gesture requirements, and
  device policy. The app-level focus layout remains available when native full
  screen cannot be entered.
- On very narrow screens, the bottom toolbar is horizontally scrollable. The
  compact playback and route controls remain available while Play Animator is
  closed.
- A player may have one Skating-lane action and one Puck-lane action in a turn.
  A second Pass or Shoot must be authored in the next turn.
- Catch-and-shoot, pass-pass, or touch-pass sequences use successive turns.
- A release marker exists only when the puck carrier has a recorded Move route.
  Stationary Pass and Shoot actions release at the start of the turn.
- Moving-receiver interception is solved iteratively from the passer's timed
  release position, puck speed, route length, and receiver route. The result is
  tuned for coaching visualization rather than laboratory ballistics.
- Moving-player pass obstruction is sampled at short intervals along the puck
  route. Extremely brief contacts between samples are theoretically possible.
- A retained straight pass that is blocked stops at an approximated contact
  point and leaves the puck loose. The app does not model a detailed pass
  deflection, stick angle, possession battle, or whistle after that contact.
- Pass bank selection uses a single wall contact and the L2 <= L1 rule. Passes do
  not yet ride the curved corners in the way that rim-around shots can.
- Shot collision checks against moving skaters use the authored turn state and
  release-time setup; they are not a continuous rigid-body solver.
- Goal physics do not separately simulate posts, crossbars, net mesh
  deformation, disputed goals, video review, or pucks wedged outside the net.
- Rounded shot boards use a densely sampled geometric boundary rather than a
  full material-contact simulation.
- Puck speed, energy retention, spin, rebound distance, and board travel are
  tuned for readable tactics instruction.
- A blocked shot or pass becomes loose. Recovery, a goalie cover, or another
  possession outcome is authored in the next turn.
- Web Audio depends on browser policy and device support. Muted tabs, silent
  mode, or unsupported browsers may suppress sound while visual goal feedback
  remains.
- The captain role is limited to one player per team. Multiple alternates are
  permitted.
