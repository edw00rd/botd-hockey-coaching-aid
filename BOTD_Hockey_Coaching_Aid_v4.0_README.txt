BOTD HOCKEY COACHING AID — VERSION 4.0
Creator: Nicholas Heller
Release date: 2026-08-03

OVERVIEW

BOTD Hockey Coaching Aid is a standalone, browser-based HTML5 tactics board for
building, drawing, animating, saving, and presenting hockey plays. It is designed
for desktop browsers with a mouse and for iPad use with touch or Apple Pencil.
The complete application is contained in index.html. It requires no account,
installation, external JavaScript library, server-side code, or network
connection after the page has loaded.

Nicholas Heller is acknowledged in the HTML source and this README as the creator
of the application, its product concept, coaching workflow, feature direction,
and user experience.

UPDATING AN EXISTING GITHUB PAGES REPOSITORY

1. Extract BOTD_Hockey_Coaching_Aid_v4.0_GitHub_Pages.zip.
2. Open the root of the repository used by GitHub Pages.
3. Upload all five extracted files. Do not upload the ZIP itself.
4. Replace the existing index.html and older preview/README files.
5. Commit the files to the branch configured under Settings > Pages.
6. Wait for the Pages deployment in the repository Actions tab to finish.
7. Reload the hosted site with Ctrl+F5 on Windows or a full refresh on iPad.

The files must be uploaded directly to the repository root. The correct entry
file is index.html, not index.htm and not a Markdown file renamed as HTML.

RUNNING LOCALLY

The same index.html can be opened directly in a current version of Microsoft
Edge, Google Chrome, Firefox, or Safari. Extract it from the ZIP before opening
it. Browser storage is specific to each site address, so a local file and a
GitHub Pages URL do not share saved plays automatically. Export the playbook JSON
from the old address and import it at the new address when necessary.

VERSION 4.0 RELEASE NOTES

PLAYER-CENTERED ACTION POPOVER

Selected-player controls have moved out of the Play Animator drawer and into a
context menu positioned beside the active rink token. The popover includes:

- player identity and role;
- possession controls;
- turn-scoped glow, color, brightness, blinking, and blink rate;
- Skating lane controls;
- Puck lane controls;
- skating-speed adjustment after a route is recorded;
- Pass, Shoot, Line Switch, and Whistle options when applicable; and
- pass-release and shot controls in player-relative option sheets.

The popover follows the selected player, remains usable in app-level focus mode,
and repositions to stay within the visible rink workspace. On smaller iPad
viewports it becomes scrollable rather than extending beyond the screen.

TIMELINE-ONLY PLAY ANIMATOR

The Play Animator drawer now concentrates on the Animation Timeline. Selected
player controls and green status/check messages were removed from the drawer to
reduce clutter. Timeline occurrences, reuse/copy controls, recorded route state,
and playhead navigation remain available.

NEW SETTINGS TAB

A SETTINGS tab now appears beside PLAYBOOK. It contains:

- Ice View: Whole Ice or Half Ice;
- Token Display: Names, Numbers, Positions, and Leadership roles; and
- Center-Ice Logo controls.

The Playbook Logo control was moved into the PLAYBOOK tab, keeping board settings
separate from playbook identity and artwork.

SIMPLIFIED MARKER TOOLBAR

The row of marker-color circles was replaced with one marker swatch. Selecting
that swatch opens a unified Marker window containing:

- color selection;
- the current hex value;
- a marker preview; and
- the drawing-width slider.

A fresh board starts with black. The most recently selected marker color and
width remain available during the working session. Pencil and Erase continue to
support mouse, touch, and Apple Pencil.

LIVE DRAWING DURING PLAYBACK AND PAUSE

The coach can draw and erase while an animation is playing and while playback is
paused at an intermediate playhead position. Marks render as a presentation
overlay above the animated rink content. Playback does not need to be reset to
add telestration. Drawing Undo, Redo, and Clear remain independent from turn and
action undo commands.

BOTTOM COMMAND CENTER

The bottom toolbar now keeps the principal authoring commands beside playback:

- <  Undo Last Action;
- << Undo Last Turn;
- check mark  Done Turn; and
- counterclockwise arrow  Cancel Current Turn.

Playback, restart, reversible scrubbing, playback speed, recorded-route controls,
and route-display mode remain available in the same command center. Disabled
commands are visibly inactive when no applicable action or turn exists.

IPAD DRAWER AND BACKGROUND FIX

The rink workspace now uses an opaque isolated compositor layer when the Play
Animator drawer is hidden on iPad. This prevents duplicated rink edges, exposed
page background, and stale drawer imagery from appearing behind the workspace.
The fix applies during drawer animation, orientation changes, and app-level focus
mode.

VERSION 4.0 STORAGE MIGRATION

Version 4.0 uses its own browser-storage namespace and checks for Version 3.6
data when no Version 4.0 session exists. Existing rosters, teams, colors,
playbooks, plays, turns, labels, uploaded images, and display settings are
normalized into the Version 4.0 interface. The new tab and popover arrangement is
an interface change; it does not intentionally discard authored play data.

A local file, a GitHub Pages URL, a custom domain, and a renamed repository are
different browser-storage origins. Export the playbook before moving the site or
clearing browser data.

BASIC VERSION 4.0 WORKFLOW

1. Open TEAMS to edit team names and colors.
2. Open ROSTER to edit members, roles, individual colors, and leadership.
3. Open SETTINGS to choose Whole Ice or Half Ice, token labels, and center logo.
4. Load active roster members to the benches and place the required objects.
5. Arrange the starting setup and assign opening possession if needed.
6. Select a rink token. Use the player-centered popover to change possession,
   author glow, select Pass/Shoot/Line Switch/Whistle, or review lane state.
7. Drag the selected token to record its skating route. Adjust skating speed in
   the same popover when needed.
8. Repeat for the other players who act during the turn. Unedited players remain
   stationary.
9. Use the bottom check-mark control to finish the turn, or use Undo Last Action,
   Undo Last Turn, and Cancel as needed.
10. Press Play or drag the playback slider in either direction.
11. Select Pencil or Erase during playback or pause to add live telestration.
12. Use PLAYBOOK to name, save, copy, import, and export plays and playbooks.

PRIVACY AND NETWORK USE

- The application makes no network requests.
- There are no analytics, accounts, trackers, advertisements, or cloud APIs.
- Uploaded logos are resized and processed locally.
- Default BOTD artwork is embedded in the HTML.
- Plays remain in the selected browser unless the user exports them.

COMPATIBILITY

Recommended desktop browsers are current Microsoft Edge, Google Chrome, Mozilla
Firefox, and Safari. The app uses Pointer Events for mouse, touch, and Apple
Pencil input. Browser handling of local file storage, Web Audio, Fullscreen, and
Apple Pencil secondary gestures can differ by platform and iPadOS version.

VERSION 4.0 TECHNICAL NOTES AND KNOWN LIMITATIONS

- The player popover is anchored to the selected token but may flip sides or move
  vertically to stay inside the viewport.
- Apple Pencil drawing and pressure-aware Pointer Events remain supported. Native
  Pencil double-tap tool cycling works only when the browser exposes that gesture
  as a secondary or barrel-button event.
- Live telestration marks are persistent coaching strokes, not time-coded video
  frames. A mark drawn during playback remains until erased, undone, or cleared.
- One movement-lane action and one puck-lane action are supported per player per
  turn. One Pass or Shoot event is supported per turn. Catch-and-shoot, touch
  passes, and pass-pass sequences use successive turns.
- Pass bank selection uses a single candidate wall contact and the established
  second-leg-less-than-or-equal-to-first-leg rule. Passes do not yet follow
  curved corners like rim-around shots.
- Moving-player obstruction is sampled at short intervals. Extremely brief
  contacts between samples are theoretically possible.
- Shot, board, rounded-corner, and net-interior behavior is a coaching-oriented
  geometric simulation, not a full rigid-body or mesh-deformation solver.
- Whistle and goal sounds depend on Web Audio, browser user-gesture policy, mute
  state, and device audio settings. Visual cues continue when sound is unavailable.
- Native full screen depends on browser and device policy. App-level focus mode
  still hides chrome and drawers when native full screen is unavailable.
- Browser storage can be removed by clearing site data. JSON export remains the
  portable backup mechanism.
