BOTD HOCKEY COACHING AID — VERSION 3.6
Creator: Nicholas Heller
Release date: 2026-08-02

OVERVIEW

BOTD Hockey Coaching Aid is a standalone, browser-based HTML5 tactics board for
building, drawing, animating, saving, and presenting hockey plays. It is designed
for a Windows desktop browser with a mouse and for iPad use with touch or Apple
Pencil. The complete application is contained in one HTML file. It requires no
account, installation, external JavaScript library, server-side code, or network
connection after the file has been downloaded.

Nicholas Heller is acknowledged in the HTML source and this README as the creator
of the application, its product concept, coaching workflow, feature direction,
and user experience.

RUNNING THE STANDALONE APPLICATION ON WINDOWS

1. Extract the standalone ZIP to a normal folder.
2. Double-click BOTD_Hockey_Coaching_Aid_v3.6.html.
3. Open it with a current version of Microsoft Edge, Google Chrome, or Firefox.
4. A local file:/// browser address is expected. The application runs locally.

Do not run the HTML from inside the ZIP archive. Extract it first so browser
storage, image uploads, and JSON exports behave consistently.

UPDATING AN EXISTING GITHUB PAGES REPOSITORY

1. Extract the GitHub Pages ZIP.
2. Upload the four extracted files to the root of the repository used by GitHub
   Pages.
3. Replace the existing index.html and matching Version 3.5 preview/README.
4. Commit the files to the branch configured under Settings > Pages.
5. Wait for the Pages deployment in the repository Actions tab to finish.
6. Reload the hosted site with Ctrl+F5 on Windows or a full refresh on iPad.

Do not upload the ZIP itself. GitHub Pages does not extract ZIP archives.

RUNNING ON IPAD OR WITH APPLE PENCIL

For the most consistent iPad experience, publish index.html on a static HTTPS
site such as GitHub Pages, open the site in Safari, and optionally choose Add to
Home Screen. The application uses Pointer Events for touch, Apple Pencil, mouse,
and trackpad input. The interface uses touch-sized controls and supports native
browser full screen where the browser permits it, plus an app-level focus mode.

VERSION 3.6 RELEASE NOTES

DIRECT ROUTE TRACING AND AUTOMATIC TURN START

Version 3.6 removes three authoring controls that required unnecessary steps:

- + New Turn;
- Move; and
- Start turn here.

A turn now begins automatically when the coach performs the first recorded
action. Every object currently on the ice is included automatically.

To record movement, select a player and drag the selected rink token along the
intended route. The time taken to trace the route remains the initial movement
timing. The route can then be retimed with the Skating speed slider. A stationary
puck carrier may Pass or Shoot without first drawing a route. A stationary staff
member may use Whistle without drawing a route.

Before the first turn exists, rink tokens can still be arranged into their setup
positions. Tap a token to select and arm it, then drag the selected token to
record the first route. Once turn authoring has begun, dragging a selected token
records movement directly.

The authoring rings remain instructional overlays:

- Green means the object has not received its movement-lane action for the
  current turn.
- Orange means a moving puck carrier still has an available puck-lane action.
- No ring means the applicable action work is complete, the player has a Line
  switch, a stationary Pass or Shoot has completed the useful lanes, or a staff
  Whistle has been assigned.

The rings and dotted selection outline remain hidden during playback and active
scrubbing.

SLIDER-ONLY MOVEMENT AND RELEASE TIMING

The quick preset buttons for skating speed and pass/shot release have been
removed. The existing precision sliders remain:

- Skating speed: 0.25x through 3.00x;
- Pass release time along a recorded route; and
- Shot release time along a recorded route.

The orange release marker can still be dragged on a skating route. Changing
movement speed preserves route geometry and recalculates route timing, release
position, moving-receiver lead, and puck geometry.

TURN-SCOPED GLOW AND BLINKING

Glow is now an authored action in the current turn rather than a permanent
player profile.

For any selected on-ice object, the Selected player card provides:

- Glow this turn;
- glow color;
- brightness from 10 percent through 100 percent;
- optional blinking; and
- blink rate from 0.25 Hz through 4.00 Hz.

Enabling Glow this turn automatically starts a turn when necessary. The glow is
stored in that turn, appears during playback of that turn, can be copied or
reused with the turn, and is included in saved plays and JSON exports. Earlier
persistent Version 3.5 glow profile fields are retained in migrated data for
compatibility but no longer control the rink display.

UNDO LAST ACTION AND UNDO LAST TURN

The Play Animator now exposes two separate correction tools:

- Undo Last Action restores the current unfinished turn to the state immediately
  before its most recently committed action. Earlier actions by other players in
  the same turn are retained.
- Undo Last Turn removes the most recent completed turn occurrence from the
  animation sequence.

Drawing Undo/Redo remains separate and affects only freehand marks.

LIVE TELESTRATION DURING PLAYBACK

Draw and Erase can now be used while playback continues. Freehand marks render
as an overlay above moving players, goalies, staff tokens, and the puck, while
remaining below active targeting controls. This supports television-style live
annotation during a presentation. The marks remain normal saved coaching strokes
and can be erased, undone, redone, or cleared independently of the animation.

APPLE PENCIL SECONDARY / DOUBLE-TAP TOOL CYCLING

When a browser exposes an Apple Pencil secondary or barrel-button event to the
web page, that event cycles the active tool in this order:

Select > Pencil > Erase > Select

A brief on-screen confirmation identifies the newly selected tool. Browser
support is the limiting factor: the web Pointer Events standard does not require
Safari or another browser to expose Apple Pencil double-tap as a secondary
button event. On browser/device combinations that do not expose the gesture, the
three toolbar buttons remain the reliable control. This is a platform limitation,
not a loss of drawing or Pencil support.

NET-INTERIOR GOAL PHYSICS

A scoring shot still becomes a goal when the puck crosses the goal line through
the open goal mouth. After that crossing:

- the two inner net side walls are reflective;
- an oblique puck can visibly rebound from an inner wall while remaining a goal;
- the back of the net is soft and stops the puck in place; and
- the puck never rebounds from the back net into open play.

The GOAL! lamp, visual celebration, and siren still trigger at the recorded
goal-line crossing. The in-net path and inner-wall contacts are stored with the
Shot action.

COACH, MANAGER, AND REFEREE / OFFICIAL TOKENS

Each fresh team now includes a Coach and a Manager on the loaded bench. Staff and
official tokens use a square shape with one horizontal stripe. The Roster Role
menu supports:

- Skater;
- Goalie;
- Coach;
- Manager; and
- Referee / Official.

Coach, Manager, and Referee / Official objects receive a Whistle action. During
playback, the action displays a WHISTLE! cue and generates a short browser-local
whistle sound through Web Audio. These objects may also be positioned or moved
like other rink objects when a diagram requires it.

TEAM AND ROSTER INTERFACE REDESIGN

The Teams panel now uses a compact diagonally split color swatch instead of
showing two color fields and hex strings on the main panel. Selecting the swatch
opens a focused color dialog containing Primary, Trim, previews, and hex values.
The color-swap control is now a compact double-arrow button.

The Roster panel now uses spaced cards with a clear top identity row, grouped
Number / Position / Role fields, a split player-color swatch, compact leadership
controls, and role guidance. Individual colors can still be changed before or
after a member is loaded to a bench; Team colors remain the default inheritance.

Fresh team defaults are exactly:

- FLAMINGOS: Primary #F100F3, Trim #FEFE00.

LEADERSHIP RULES

- One Captain is permitted per team.
- No more than two Alternate captains are permitted per team.
- Captain and Alternate remain mutually exclusive for one roster member.
- Goalie leadership controls appear visually muted but remain selectable.
- Selecting C or A for a Goalie displays the warning:
  Are you sure you want to make the "tendy" a Captain?
- Confirm applies the leadership role; Cancel leaves it unchanged.

Deleting a roster member remains immediate and does not display a confirmation
prompt.

BASIC VERSION 3.6 WORKFLOW

1. Open Teams, choose Whole ice or Half ice, edit team names, and select the split
   swatch to edit colors.
2. Open Roster to edit bench membership, identity, Role, individual colors, and
   leadership.
3. Select Load active players to benches after changing active membership.
4. Select bench tokens to place rink objects, then arrange the starting setup.
5. Place the loose puck or assign opening possession.
6. Select a rink object. Drag it to record a route, or choose Pass, Shoot, Line
   switch, Whistle, possession, or Glow this turn as applicable. The first action
   starts the turn automatically.
7. Repeat for other objects that change. Unedited objects remain stationary.
8. Refine route timing with the Skating speed slider.
9. For a moving Pass or Shot, set release timing with the release slider or the
   orange draggable marker.
10. Select Done turn.
11. Repeat the direct action workflow for later turns.
12. Press Play or drag the playback slider in either direction.
13. Use Draw or Erase during playback for live telestration.
14. Use Undo Last Action while a turn is open, or Undo Last Turn after completion.
15. Name and save the play, then export playbook JSON backups.

PASSING AND SHOOTING WITHOUT A ROUTE

A puck carrier does not need a Move action. Select the stationary carrier and
choose Pass or Shoot. The event releases at the start of the turn. Pass continues
to default to Ignore defense enabled; Shot continues to default to Ignore
defense disabled.

PASSING OR SHOOTING ON THE MOVE

1. Select and drag the puck carrier to record a timed route.
2. Record a receiver route and other player routes when needed.
3. Reselect the carrier and choose Pass or Shoot.
4. Use the release slider or orange route marker to choose the release moment.
5. Complete the target/options dialog.
6. Select Done turn.

The puck stays attached to the carrier until release. A pass leads a moving
receiver using the authored timing. The carrier continues skating after release.
One Pass or Shoot event remains permitted per turn.

DRAWING CONTROLS

- Select: select rink objects and record direct movement by dragging the selected
  object.
- Pencil: draw with mouse, touch, or Apple Pencil, including during playback.
- Erase: cross a freehand stroke to remove the whole stroke, including during
  playback.
- Preset and custom colors plus line-width adjustment remain available.
- Drawing Undo, Redo, and Clear are independent of turn Undo controls.

PLAYBOOK, STORAGE, AND FILES

- The named default collection remains BOTD Playbook.
- The three core sample plays remain available: whole-ice 5v5, portrait half-ice
  5v5, and whole-ice 2v1.
- Save play updates the current entry; Save copy creates another entry.
- Export downloads one portable play JSON file.
- Export playbook downloads the complete named playbook as JSON.
- Import accepts compatible play and playbook JSON from earlier releases.
- Browser-local storage is device- and site-specific. Export important work.

VERSION 3.6 STORAGE MIGRATION

Version 3.6 uses:

- botdHockeyCoachingAid.session.v3_6
- botdHockeyCoachingAid.playbook.v3_6

When Version 3.6 data is absent, the app checks Version 3.5 data first and then
the earlier supported namespaces. Existing sessions, plays, colors, labels,
turns, samples, and playbook identity are retained. Version 3.6 normalizes new
Role and action fields, limits migrated Alternate designations to two per team,
and leaves user-created rosters intact. The new 10-skater / 2-goalie / 2-staff
roster is applied only to a fresh session or the New command.

A local file, a GitHub Pages URL, a custom domain, and a renamed repository are
different browser-storage origins. Export the playbook before moving the site or
clearing browser data.

VERSION 3.6 TECHNICAL NOTES AND KNOWN LIMITATIONS

- Apple Pencil drawing and pressure-aware Pointer Events remain supported. Native
  Pencil double-tap tool cycling works only when the browser exposes that gesture
  as a secondary/barrel-button event.
- Direct movement recording uses pointer samples and the elapsed trace time. It
  does not model biomechanical acceleration, edge work, fatigue, or a real
  player's maximum speed.
- Undo Last Action restores the most recent committed draft-action snapshot. It
  is not a general keystroke-by-keystroke undo for every slider sample.
- Turn-scoped glow is a visual action and does not affect possession, collision,
  scoring, team identity, or line changes. Reduced-motion browser preferences
  may suppress blinking while retaining a steady glow.
- Live telestration marks are persistent coaching strokes, not time-coded video
  frames. A mark drawn during playback remains until erased, undone, or cleared.
- Whistle and goal sounds depend on Web Audio, browser user-gesture policy, mute
  state, and device audio settings. Visual cues continue when sound is unavailable.
- Staff and official tokens are diagram objects. The app does not enforce bench,
  officiating, or league eligibility rules for their placement.
- One movement-lane action and one puck-lane action are supported per player per
  turn. One Pass or Shoot event is supported per turn. Catch-and-shoot, touch
  passes, and pass-pass sequences use successive turns.
- Pass bank selection still uses a single candidate wall contact and the
  established L2 <= L1 rule. Passes do not yet follow curved corners like a
  rim-around Shot.
- Moving-player obstruction is sampled at short intervals. Extremely brief
  contacts between samples are theoretically possible.
- Shot, board, rounded-corner, and net-interior behavior is coaching-oriented
  geometric simulation, not a full rigid-body, mesh-deformation, or CFD solver.
- Inner net side walls are line segments; the soft back net stops the puck at the
  modeled rear plane. Posts, crossbars, mesh stretch, pucks wedged outside the
  net, review, and disputed goals are not separately simulated.
- Goalie leadership uses a native browser confirmation dialog. Browser wording
  and button order around Confirm/Cancel may vary by platform.
- Native full screen depends on browser and device policy. The app-level focus
  mode still hides chrome and drawers when native full screen is unavailable.
- Browser storage can be removed by clearing site data. JSON export remains the
  portable backup mechanism.
