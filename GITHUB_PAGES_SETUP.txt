BOTD HOCKEY COACHING AID v3.3 - GITHUB PAGES SETUP

IMPORTANT FIX
-------------
The deployable application is the file named index.html. Its first line is:
<!doctype html>

Do not rename README.md to index.html. README.md contains repository documentation, not the application.

UPLOAD
------
1. Extract this ZIP.
2. Open the extracted folder.
3. Upload the FILES INSIDE the folder directly into the root of your GitHub repository.
4. Confirm index.html is about 630 KB and begins with <!doctype html>.
5. In GitHub, open Settings > Pages.
6. Choose Deploy from a branch.
7. Select main and / (root), then Save.
8. Wait for the Pages deployment to show a green check mark.
9. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

REPAIRING A SITE THAT SHOWS README TEXT
---------------------------------------
1. In the repository root, open index.html.
2. Delete that file if it begins with # BOTD Hockey Coaching Aid instead of <!doctype html>.
3. Upload the index.html supplied in this package.
4. Commit the change.
5. Wait for Pages to redeploy, then refresh with Ctrl+F5.
