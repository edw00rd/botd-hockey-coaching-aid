BOTD HOCKEY COACHING AID — VERSION 4.3
Creator: Nicholas Heller
Release date: 2026-08-03

OVERVIEW

BOTD Hockey Coaching Aid is a standalone, browser-based HTML5 coaching board for
building, drawing, animating, saving, and presenting hockey plays. It is designed
for desktop browsers with a mouse and for iPad use with touch or Apple Pencil.
The complete application is contained in index.html. It requires no account,
installation, external JavaScript library, server-side application, database, or
runtime asset folder.

Nicholas Heller is acknowledged in the HTML source and this README as the creator
of the application, its product concept, coaching workflow, feature direction,
and user experience.

DEPLOYING TO AN EXISTING GITHUB PAGES REPOSITORY

1. Extract BOTD_Hockey_Coaching_Aid_v4.3_GitHub.zip on the computer.
2. Open the root of the repository used by GitHub Pages.
3. Upload index.html, README.txt, Preview.png, and .nojekyll. Do not upload the
   ZIP itself.
4. Replace the repository's existing files with the four Version 4.3 files.
5. Commit the files to the branch configured under Settings > Pages.
6. Wait for the Pages deployment under the repository's Actions tab to finish.
7. Reload the hosted site with Ctrl+F5 on Windows, or perform a full refresh in
   Safari on iPad.

The four files must be placed directly in the repository root. The site entry
file must remain index.html. GitHub Pages does not require a build system for this
application.

RUNNING LOCALLY

Open index.html in a current version of Microsoft Edge, Google Chrome, Mozilla
Firefox, or Safari. A local file address and a GitHub Pages address use separate
browser-storage origins, so saved plays do not move between them automatically.
Export the Playbook JSON from the old address and import it at the new address
when changing locations.

VERSION 4.3 RELEASE NOTES

ORDERED POSSESSION, SKATING, AND PUCK-ACTION AUTHORING

Version 4.3 makes the action sequence explicit and prevents contradictory timing.
For a player who will collect and use the puck during a turn, the intended order
is:

1. Possession decision.
2. Skating route.
3. Pass or Shot.
4. Independent timing adjustment for both action lanes.
5. Done Turn.

- Possession must be chosen before route tracing begins.
- As soon as a player starts a skating trace, the possession control is hidden
  and locked for that player for the remainder of the unfinished turn.
- Starting movement without arming possession means that player will not take a
  new loose-puck possession during that turn.
- A player who already carried the puck into the turn retains that carried state
  unless possession is deliberately changed before movement begins.
- Pass and Shot are not offered until the player has a recorded Skating Lane and
  is the intended puck carrier.
- The turn cannot be completed with an unresolved armed pickup or with a puck
  action that lacks its required possession and movement stages.

ROUTE-BASED DELAYED PUCK PICKUP

When a player is armed to collect a loose puck and then receives a skating route,
the application no longer grants possession at time zero.

- The route is evaluated segment by segment.
- The nearest point on the recorded route to the puck is calculated, including a
  projected point between recorded vector samples rather than only the original
  sample nodes.
- The corresponding route timestamp becomes the pickup time.
- Before that time, the puck remains loose at its starting position.
- At the pickup time, the puck attaches to the player and follows the player's
  RH/LH carrying side.
- Changing the player's skating-speed multiplier recalculates the pickup time.
- A Pass or Shot release cannot be trimmed earlier than the calculated pickup.

INDEPENDENT SKATING-LANE AND PUCK-LANE TRIMMING

After a route and puck action are present, one combined timing workspace appears
in Player Actions so the coach can tune the play without moving between windows.

Skating Lane controls include:

- An independent speed multiplier from 0.25x through 3.00x.
- Updated route duration.
- The calculated loose-puck pickup time when applicable.

Shot controls include:

- Shot power from 1 through 10.
- Release point along the skating route.
- Preview playhead for examining the turn before completion.
- Ignore defense, retained from the preceding release.

Pass controls include:

- Puck speed/power from 1 through 10.
- Flat or saucer selection.
- Release point along the skating route.
- Preview playhead.
- Ignore defense, retained from the preceding release.

Changing skating speed preserves the route shape. Pickup time, moving-pass
geometry, shot origin, receiver lead, travel time, and release limits are then
recalculated. Changing puck power affects puck travel speed without changing the
skater's route. All controls remain editable until the bottom-toolbar Done Turn
check mark is selected.

PERSISTENT TURN GLOW

Glow remains a turn action, but Version 4.3 also carries the selected state into
later turns until the coach turns it off.

- Checking Glow applies the highlight from the beginning of the current turn.
- The color, brightness, blinking state, and blink rate are stored as the active
  carry-forward profile.
- The next turn begins with a matching Glow action for that on-ice player.
- Unchecking Glow in a later turn removes the highlight from that turn forward.
- Cancel Turn restores the glow state that existed before the canceled draft.
- Copy, reuse, saved plays, Playbooks, and JSON retain the relevant turn actions
  and player glow state.

BLANK NEW PLAYS AND QUICK SETUP PLAYBOOK ENTRIES

Fresh Version 4.3 boards and the New command now begin with every roster member on
the bench and nobody on the ice. This removes unwanted starting objects and lets
the coach build a clean drill from scratch.

BOTD Playbook includes four quick-load setup entries:

- Quick Setup — 5v5 Center Faceoff
  Five skaters and one goalie per side, with a loose puck on the center dot.
- Quick Setup — 3v3 Center Faceoff
  Three skaters and one goalie per side, with a loose puck on the center dot.
- Quick Setup — 3v2 Rush
  Three onside attackers against two defenders, with both goalies included.
- Quick Setup — 2v1 Rush
  Two onside attackers against one defender, with both goalies included.

The center-faceoff templates use conventional USA Hockey-compatible faceoff
spacing. The 3v2 and 2v1 entries are onside coaching-drill arrangements rather
than formations prescribed by a playing rule. The application remains a tactical
visualization tool and is not an officiating reference.

INITIAL OFFSIDE NORMALIZATION

A play is assumed to begin in a legal setup state.

- The first reconstructed frame cannot immediately display a blinking-red
  delayed-offside infraction solely because of imported or starting geometry.
- A starting frame with an attacker ahead of a puck that remains outside the
  offensive zone may display orange, indicating that a tag-up is needed.
- Once playback advances, the existing stateful tracker can progress through
  green, orange, blinking red, tag-up, and legal re-entry states.
- Fresh blank boards and all four Version 4.3 quick setups initialize onside.

HALF-ICE CENTER-LOGO PRESENTATION

In portrait Half Ice, the center artwork now uses a dedicated image element that
is rotated 90 degrees and clipped to the visible half of the center-ice area.
Custom uploaded center logos use the same treatment. Whole Ice continues to show
the complete unrotated logo.

BASIC VERSION 4.3 WORKFLOW

1. Open TEAMS to edit team names and colors.
2. Open ROSTER to edit names, numbers, positions, roles, lines, RH/LH handedness,
   individual colors, and leadership.
3. Open SETTINGS to choose Whole Ice or Half Ice, token labels, center logo, and
   offside-indicator visibility.
4. For a blank board, tap bench entries to place the required objects. Bench
   placement does not open Player Actions automatically.
5. Alternatively, open PLAYBOOK and load a 5v5, 3v3, 3v2, or 2v1 Quick Setup.
6. Select a rink token directly to open Player Actions.
7. Before moving, turn on Possession when that player should collect a loose puck
   during the turn.
8. Drag the player to trace the Skating Lane. The possession choice then locks.
9. When possession was armed, the app calculates the closest route point to the
   puck and displays the pickup time.
10. Choose Pass or Shot after the skating route exists.
11. Fine-tune Skating speed and Puck Lane power, release, sauce, defense handling,
    and preview together.
12. Set or clear Glow at any time before Done Turn.
13. Select the bottom-toolbar check mark to finish the turn.
14. Use Undo Last Action, Undo Last Turn, or Cancel to correct authoring.
15. Press Play or scrub the playback slider in either direction.
16. Pencil and Erase remain available during active or paused playback for live
    telestration.
17. Save the play to BOTD Playbook and export JSON for backup or transfer.

VERSION 4.3 STORAGE AND MIGRATION

Version 4.3 uses its own browser-storage namespace:

- botdHockeyCoachingAid.session.v4_3
- botdHockeyCoachingAid.playbook.v4_3

When no Version 4.3 data exists, the application checks Version 4.2 data and
normalizes it into Version 4.3. Existing teams, rosters, lines, handedness,
leadership, logos, drawing settings, turns, routes, puck actions, glow actions,
notes, and user-created Playbook entries are retained when compatible.

The four Version 4.3 quick setups replace the earlier built-in sample entries.
User-created Playbook items are preserved. Version 4.2 saved plays continue to
load through the normal state-normalization path; new pass-power and delayed-
pickup fields receive safe defaults when they did not exist in the older data.

Browser storage is isolated by origin. A local file, a GitHub Pages URL, a custom
domain, and a renamed repository are separate origins. Export Playbook JSON
before moving the site, changing its URL, or clearing browser data.

PRIVACY AND NETWORK USE

- The application makes no network requests.
- There are no analytics, accounts, trackers, advertisements, or cloud APIs.
- Uploaded logos are resized and processed locally.
- Default BOTD artwork is embedded in the HTML.
- Plays remain in the selected browser unless the user exports them.

COMPATIBILITY

Recommended desktop browsers are current Microsoft Edge, Google Chrome, Mozilla
Firefox, and Safari. The app uses Pointer Events for mouse, touch, and Apple
Pencil input. Browser handling of local-file storage, Web Audio, Fullscreen, and
Apple Pencil secondary gestures can vary by platform and iPadOS/browser version.

VERSION 4.3 TECHNICAL NOTES AND KNOWN LIMITATIONS

- Route-based pickup uses the nearest mathematical point on the traced polyline.
  It does not currently require the route to enter a fixed stick-reach radius.
- The offside tracker is a tactical coaching aid. It uses token centers and app
  coordinates rather than skate/blade geometry, video review, every delayed-
  offside exception, or a governing body's officiating system.
- Attack direction is fixed to Team A/right and Team B/left on whole ice.
- A single Pass or Shot event per turn remains the clearest supported model. A
  pass-pass or catch-and-shoot sequence should use consecutive turns.
- Puck and board behavior is designed for coaching visualization rather than a
  complete rigid-body or fluid-dynamics simulation.
- Browser-local storage is not a shared team database. Export Playbook JSON for
  backups and transfers between devices or origins.
- Native Apple Pencil double-tap exposure remains browser- and iPadOS-dependent;
  the Select, Pencil, and Erase toolbar controls are always available.
- Responsive checks were performed in Chromium-emulated desktop and iPad
  viewports. Physical-device behavior can still vary with Safari and iPadOS.
