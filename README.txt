BOTD HOCKEY COACHING AID — VERSION 4.1
Creator: Nicholas Heller
Release date: 2026-08-03

OVERVIEW

BOTD Hockey Coaching Aid is a standalone, browser-based HTML5 coaching board for
building, drawing, animating, saving, and presenting hockey plays. It is designed
for desktop browsers with a mouse and for iPad use with touch or Apple Pencil.
The application is entirely contained in index.html and requires no account,
installation, external JavaScript library, server-side application, or runtime
asset folder.

Nicholas Heller is acknowledged in the HTML source and this README as the creator
of the application, its product concept, coaching workflow, feature direction,
and user experience.

GITHUB PACKAGE CONTENTS

The Version 4.1 ZIP contains exactly these three current files at its root. There
is no enclosing folder.

- index.html
  The complete Version 4.1 application and GitHub Pages entry point.
- README.txt
  Deployment instructions, Version 4.1 release notes, operating guidance, known
  limitations, migration notes, verification details, and the complete detailed
  history from Version 0.1 through Version 4.1.
- Preview.png
  A 1920 x 1080 preview generated from this exact Version 4.1 build.

All BOTD artwork, rink graphics, sample rosters, sample plays, audio synthesis,

DEPLOYING TO AN EXISTING GITHUB PAGES REPOSITORY

1. Extract BOTD_Hockey_Coaching_Aid_v4.1_GitHub.zip on the computer.
2. Open the root of the repository used by GitHub Pages.
3. Upload index.html, README.txt, and Preview.png. Do not upload the ZIP itself.
4. Replace the repository's existing index.html and the prior README/preview.
5. Commit the files to the branch configured under Settings > Pages.
6. Wait for the Pages deployment under the repository's Actions tab to finish.
7. Reload the hosted site with Ctrl+F5 on Windows, or perform a full refresh in
   Safari on iPad.

The files must be placed directly in the repository root. The site entry file
must remain index.html. GitHub Pages does not need a build system for this app.

RUNNING LOCALLY

Extract index.html from the ZIP and open it in a current version of Microsoft
Edge, Google Chrome, Mozilla Firefox, or Safari. A local file address and a
GitHub Pages address use separate browser-storage origins, so saved plays do not
move between them automatically. Export the Playbook JSON from the old address
and import it at the new address when changing locations.

VERSION 4.1 RELEASE NOTES

DIRECT-SELECTION PLAYER ACTIONS DRAWER

Player Actions now opens in a dedicated right-side drawer only after the coach
directly selects a token on the rink.

- Placing a skater, goalie, coach, manager, or official from a bench no longer
  selects that object.
- Bench placement no longer opens Player Actions or interrupts rapid setup.
- Keyboard activation of a focused rink token is treated as a direct selection
  for accessibility.
- Closing the drawer clears the selected object. Selecting empty ice also closes
  the drawer through the normal rink-selection behavior.
- The drawer remains available in app-level focus/full-screen mode and is sized
  to stay inside desktop and iPad viewports.
- Programmatic selection changes created by Pass, Line Switch, or other timeline
  logic do not open the drawer unexpectedly.

CONTEXTUAL, LESS-IS-MORE ACTION CONTROLS

The Player Actions drawer now displays only controls that apply to the selected
object and current state.

- Possession remains visible as the primary state control.
- The Puck lane is hidden when the selected player does not possess the puck.
- Pass and Shoot appear immediately when possession is enabled and no conflicting
  puck action exists.
- Line Switch is hidden and guarded while the selected player possesses the puck.
- Taking possession removes an already-authored Line Switch for that player,
  preventing a contradictory turn state.
- Line Switch is also hidden when no eligible bench replacement exists.
- With only one eligible on-ice player, Pass remains visible but is disabled and
  visibly gray. It unlocks as soon as another eligible player is on the ice.
- Staff objects continue to receive their Whistle controls when applicable.
- The skating instruction remains visible without presenting an unnecessary Move
  button: drag the selected rink token to author its route, or leave it stationary.

NESTED TURN GLOW EDITOR

The former inline "Glow this turn" controls were reduced to one compact Glow
button. Selecting it opens a focused nested window containing:

- Glow on/off for the current turn;
- glow color;
- brightness;
- optional blinking; and
- blink rate.

Glow remains a turn-scoped Highlight action rather than a permanent player
profile property. It is retained by Undo Last Action, turn copying/reuse, saved
plays, Playbook data, and JSON import/export.

DISCREET OFFSIDE STATUS LIGHT

A small status light now appears in the upper-right corner of the rink.

- Green means the inferred attacking team is onside.
- Dark yellow means an attacking object is across the offensive blue line while
  the puck has not yet entered the zone.
- The light has no visible label. Hovering it with a mouse displays its status
  and description; an accessible label is also provided for assistive software.
- Staff objects are excluded from the calculation.
- During ordinary editing, the attacking team is inferred from possession.
  During active Pass or Shot playback, the acting player's team is used while
  the puck is loose.
- Whole-ice calculation assumes Team A attacks to the right and Team B attacks
  to the left. Half-ice uses the single offensive-zone blue line.

The indicator is a coaching aid, not an officiating or video-review system. It
uses token centers and the app's tactical coordinates rather than skate/blade
geometry, delayed-offside tags, or every exception in a governing body's rules.

FLUID SELECTED-PLAYER WHEEL AND SOUND

Directly selecting a rink token gives the dashed selection ring more character:

- the dashes travel around the token with changing apparent acceleration;
- a short locally synthesized "vroom vroooom" engine sweep plays when browser
  audio policy and device sound settings permit it; and
- the wheel stops as soon as route tracing begins, keeping the movement path
  visually clear.

Reduced-motion browser preferences disable the wheel animation. The visual
selection remains usable when audio is muted or unavailable.

APPLE PENCIL AND LIVE-INK RELIABILITY

The drawing input path was rebuilt around a document-capture Pointer Events
owner so Pencil and Erase receive each contact before older rink handlers.

- Consecutive Apple Pencil contacts now reset independently instead of every
  other touch being consumed by stale pointer state.
- Pencil, touch, and mouse drawing remain available during active playback and
  while paused at an intermediate playhead position.
- Coalesced pointer samples are retained for smoother Pencil strokes.
- Lost-pointer-capture, pointer-cancel, and a newly arriving Pencil contact all
  finalize the prior stroke safely.
- A short palm-rejection window ignores touch contacts immediately following a
  Pencil contact.
- Telestration remains an overlay and does not pause playback.

VERSION 4.1 STORAGE AND MIGRATION

Version 4.1 uses its own browser-storage namespace:

- botdHockeyCoachingAid.session.v4_1
- botdHockeyCoachingAid.playbook.v4_1

When no Version 4.1 data exists, the app checks Version 4.0 and then earlier
supported storage keys. Existing teams, rosters, colors, staff, leadership,
logos, marker settings, plays, turns, route timing, glow actions, and Playbook
data are normalized into Version 4.1.

Browser storage is isolated by origin. A local file, a GitHub Pages URL, a custom
domain, and a renamed repository are separate origins. Export Playbook JSON
before moving the site, changing its URL, or clearing browser data.

BASIC VERSION 4.1 WORKFLOW

1. Open TEAMS to edit team names and colors.
2. Open ROSTER to edit members, roles, individual colors, and leadership.
3. Open SETTINGS to choose Whole Ice or Half Ice, token labels, and center logo.
4. Load the required roster members to the benches.
5. Tap or click bench entries to place them. They are not selected automatically.
6. Arrange the starting setup and position a loose puck as required.
7. Select a rink token directly to open the Player Actions drawer.
8. Toggle Possession when that object has the puck. Pass and Shoot then appear.
9. Drag the selected token to record its route, or leave it stationary.
10. Use Glow to open the nested turn-highlight editor when emphasis is needed.
11. Repeat for the other objects acting during the turn. Unedited objects remain
    stationary.
12. Use the bottom check-mark control to finish the turn. Use Undo Last Action,
    Undo Last Turn, or Cancel to correct the sequence.
13. Press Play or drag the playback slider in either direction.
14. Select Pencil or Erase during playback or pause to add live telestration.
15. Use PLAYBOOK to name, save, copy, import, and export plays and Playbooks.

PRIVACY AND NETWORK USE

- The application makes no network requests.
- There are no analytics, accounts, trackers, advertisements, or cloud APIs.
- Uploaded logos are resized and processed locally.
- Default BOTD artwork is embedded in the HTML.
- Plays remain in the selected browser unless the user exports them.

COMPATIBILITY

Recommended desktop browsers are current Microsoft Edge, Google Chrome, Mozilla
Firefox, and Safari. The app uses Pointer Events for mouse, touch, and Apple
Pencil input. Browser handling of local-file storage, Web Audio, Fullscreen, and
Apple Pencil secondary gestures can vary by platform and iPadOS/browser version.

VERSION 4.1 TECHNICAL NOTES AND KNOWN LIMITATIONS

- The dedicated Player Actions drawer overlays the right side of the workspace;
  closing it reveals the Animation Timeline underneath.
- Offside status is a tactical approximation based on token centers, the puck
  coordinate, and the inferred attacking direction. It does not model tag-up,
  intentional offside, deflections that reset control, or every league variation.
- The selection sound is generated with Web Audio and may be silent until a
  browser accepts a user gesture, when the device is muted, or under system
  accessibility/audio policy.
- Native Apple Pencil double-tap tool cycling remains best-effort because Safari
  does not expose that hardware gesture consistently. Toolbar controls remain
  the dependable fallback.
- Live telestration strokes are persistent coaching overlays, not time-coded
  video frames. A stroke drawn during playback remains until erased, undone, or
  cleared.
- One movement-lane action and one puck-lane action are supported per player per
  turn. One Pass or Shoot event is supported per turn. Catch-and-shoot, touch
  passes, and pass-pass sequences use successive turns.
- Pass bank selection uses one candidate wall contact and the established rule
  that the second leg must be no longer than the first. Passes do not yet follow
  curved corners like rim-around shots.
- Moving-player obstruction is sampled at short intervals. Extremely brief
  contacts between samples are theoretically possible.
- Shot, board, rounded-corner, and net-interior behavior is a coaching-oriented
  geometric simulation, not a full rigid-body or mesh-deformation solver.
- Whistle, vroom, and goal sounds depend on Web Audio, browser user-gesture
  policy, mute state, and device settings. Visual cues continue without sound.
- Browser storage can be removed by clearing site data. JSON export remains the
  portable backup mechanism.
