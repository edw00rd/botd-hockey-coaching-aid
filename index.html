# BOTD Hockey Coaching Aid v3.3 A standalone, browser-based hockey coaching board created by **Nicholas Heller**. ![BOTD Hockey Coaching Aid preview](BOTD_Hockey_Coaching_Aid_v3.3_Preview.png) ## Run the site Open `index.html` in a browser, or publish the contents of this folder with GitHub Pages. ## Publish with GitHub Pages 1. Create a GitHub repository, such as `botd-hockey-coaching-aid`. 2. Upload every file in this folder to the repository root. 3. Commit the files to the `main` branch. 4. In the repository, open **Settings > Pages**. 5. Select **Deploy from a branch** as the source. 6. Select the `main` branch and the `/ (root)` folder, then save. 7. After deployment completes, the project site is normally available at: `https://YOUR-USERNAME.github.io/botd-hockey-coaching-aid/` If the repository itself is named `YOUR-USERNAME.github.io`, the site is normally available at: `https://YOUR-USERNAME.github.io/` ## Important data note The application stores its working session and locally saved plays in the browser. GitHub Pages hosts the application but does not provide a playbook database or account synchronization. Data saved in one browser or device will not automatically appear on another. Before moving from the locally opened HTML file to the hosted site, use the application's **Export playbook** control. Then use **Import JSON** on the hosted copy. Continue exporting periodic backups. ## Updating the hosted version Replace `index.html` with the newer release, replace the preview and documentation as needed, and commit the changes to `main`. GitHub Pages will redeploy the site. ## Files - `index.html` — deployable application - `BOTD_Hockey_Coaching_Aid_v3.3_Preview.png` — release preview - `BOTD_Hockey_Coaching_Aid_v3.3_README.txt` — full cumulative release notes and operating guide - `.nojekyll` — tells GitHub Pages to serve the folder as plain static files ## Privacy and hosting model The application is client-side only. It has no application server, user accounts, shared database, analytics, or automatic cloud backup. Uploaded logos and playbook content remain in the current browser unless the user exports them.
